# Экран «Каталог упражнений» (`CatalogScreen`)

**Маршрут:** `RouteCatalog` (`IronLogRoot.kt`)  
**Файлы реализации:**  
- `app/src/main/java/com/example/ui/screens/CatalogScreen.kt`  
- `app/src/main/java/com/example/ui/components/AthleticCharts.kt` (`ExercisePoseAnimationCanvas`)  
- `core/src/main/java/com/example/ironlog/core/seed/ExerciseCatalogSeed.kt`

---

## 1. Продуктовое описание

Полный справочник упражнений для изучения техники, просмотра личных рекордов и пополнения базы собственными движениями.

### Основные пользовательские сценарии
1. **Поиск и многоуровневая фильтрация:**
   - Текстовое поле поиска (`catalog_search_input`) ищет совпадения одновременно по русскому и английскому названиям.
   - Первая лента `FilterChip` фильтрует по **13 группам мышц** (`Грудь`, `Спина`, `Плечи`, `Бицепс`, `Трицепс`, `Предплечья`, `Квадрицепс`, `Бицепс бедра`, `Ягодицы`, `Икры`, `Пресс и кор`, `Всё тело`, `Кардио`) — совпадение проверяется как по основной, так и по вторичным мышцам.
   - Вторая лента фильтрует по **9 типам инвентаря** (`Штанга`, `Гантели`, `Тренажёр`, `Блок / Кроссовер`, `Свой вес`, `Гиря`, `Резинка`, `Кардио-тренажёр`, `Другое`), а `Switch` управляет отображением архивных упражнений.
2. **Карточка упражнения в списке:**
   - Отображает статическую мини-иллюстрацию позы (`60.dp`), локализованное название, метку `CUSTOM` (для пользовательских), теги мышц/инвентаря/категории, тип измерения и бейдж лучшего PR (если есть).
3. **Окно деталей упражнения:**
   - По тапу открывается диалог с **анимированной векторной демонстрацией техники** (`ExercisePoseAnimationCanvas`, `animate = true`), подробным описанием техники, карточкой PR (`Max` и расчётный `1RM`) и действиями:
     - **Архивировать / Разархивировать** (доступно для любого упражнения, скрывает его из пикеров тренировок и списка по умолчанию);
     - **Редактировать / Удалить** (только для пользовательских упражнений `isCustom = true`).
4. **Создание и редактирование упражнения (`ExerciseEditorDialog`):**
   - Кнопка `FAB` (`create_exercise_fab`) открывает форму создания упражнения: названия (`RU`/`EN`), описания техники (`RU`/`EN`), выбор основной группы мышц, инвентаря, категории (`Базовое`, `Изолирующее`, `Тяжёлая атлетика`, `Плиометрика`, `Статика`, `Кардио`) и типа измерения (`MeasurementType`).

## 2. Техническое описание

### Предзаполнение и структура данных
- При первом запуске приложения `WorkoutRepository.ensureSeeded()` внутри транзакции Room записывает **49 базовых упражнений** из `ExerciseCatalogSeed.defaultExercises`, если таблица `exercises` пуста.
- Для корректных отступов внутри корневого `Scaffold` вложенный `Scaffold` экрана каталога использует `contentWindowInsets = WindowInsets(0, 0, 0, 0)`, чтобы исключить двойной нижний/верхний инсет (системные бары уже учтены на уровне `IronLogRoot`).

### Процедурная анимация техники (`ExercisePoseAnimationCanvas`)
- Отрисована на Jetpack Compose `Canvas` без внешних видео/GIF-ресурсов (что критично для минимального размера APK и работы офлайн).
- В списке (`animate = false`) используется фиксированная фаза `t = 0.5f`; в диалоге деталей (`animate = true`) запускается бесконечный `rememberInfiniteTransition` с `tween(1500, LinearEasing)` и `RepeatMode.Reverse`, анимирующий кинематику 12 поз (`BENCH_PRESS`, `SQUAT`/`LUNGE`, `DEADLIFT`/`ROW`, `OVERHEAD_PRESS`, `PULL_UP`, `CURL`/`EXTENSION`, `PLANK`, `CARRY`/`CARDIO`).

### Синхронизация и защита базовых упражнений
- Кастомные упражнения получают ID вида `"custom_${UUID.randomUUID()}"` и флаг `isCustom = true`.
- При сохранении или удалении кастомного упражнения в таблицу `sync_operations` добавляется запись `entityType = "exercise"` с `pendingPush = true`, что позволяет синхронизировать пользовательские упражнения с Wear OS; базовые упражнения удалять нельзя (их можно только архивировать).
